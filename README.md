#  Arduino From Scratch

Learning Arduino, sensors, and embedded circuits from scratch using Tinkercad simulator.

##  Projects Included
- **01-led-blinking**: Basic LED blinking circuit.
- **02-two-leds**: Alternating dual-LED control.
- **03-led-light**: Traffic light system implementation.
- **04-RGB LED**: Multi-color RGB mixing logic.
- **Potentiometer-Analog-Input**: Reading analog values with potentiometer.

  Stack & Tools
- Arduino C / C++
- Tinkercad Simulator
