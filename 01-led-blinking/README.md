# 01 — LED Blinking

## Objective

Create a simple circuit that makes a LED blink using Arduino.

## Components

* Arduino Uno
* LED

## What I Learned

* How to configure a digital pin as an output using `pinMode()`.
* How to turn an LED on and off using `digitalWrite()`.
* How to use `delay(1000)` to wait for one second.
* The difference between `setup()` and `loop()`.

## How It Works

The Arduino configures pin 13 as an output. The LED turns on for one second, then turns off for one second. This process repeats continuously.

## Tools

* Tinkercad Circuits
* Arduino C++

## Next Step

Experiment with different delay values to change the blinking speed.
