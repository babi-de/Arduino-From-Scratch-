# 02 — Two LEDs Blinking

## Objective

Control two LEDs using two digital output pins on an Arduino Uno.

## Components

* Arduino Uno
* Two LEDs
* Breadboard
* Resistors
* Jumper wires

## What I Learned

* How to configure multiple digital pins as outputs.
* How to control each LED using its own pin.
* How to use `HIGH` and `LOW` to control digital outputs.
* How instructions inside `loop()` execute repeatedly and in order.

## How It Works

Pin 8 turns on for one second and then turns off for one second. Next, pin 4 turns on for one second and then turns off for one second. The sequence repeats continuously.

## Tools

* Tinkercad Circuits
* Arduino C++

## Next Step

Modify the sequence to make both LEDs turn on together.
