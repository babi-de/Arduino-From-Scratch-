# 03 - Arduino Traffic Light 

## Project Overview
This is my third Arduino project. I created a simple traffic light system using three LEDs: red, yellow, and green.

## Components
- Arduino Uno
- 1 red LED
- 1 yellow LED
- 1 green LED
- 3 resistors
- Breadboard
- Jumper wires

## Pin Connections
- Red LED: Pin 12
- Yellow LED: Pin 4
- Green LED: Pin 2

## How It Works
The LEDs light up in sequence to simulate a traffic light. Each LED is controlled using `digitalWrite()`, and `delay()` controls the time between changes.

## What I Learned
- Configuring output pins with `pinMode()`
- Turning LEDs on and off using `digitalWrite()`
- Controlling timing with `delay()`
- Connecting LEDs with resistors
- Understanding the basic logic of a traffic light
